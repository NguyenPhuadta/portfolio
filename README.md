# Nguyễn Hồng Phú — Portfolio Draft

Light-theme portfolio draft inspired by the interaction model of the Ultraminimal reference.

## Preview

Run a local static server from this folder:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Draft scope

- Light theme and narrow editorial layout
- Product Case Studies / Visual Archive filters
- Scroll reveal and interactive project covers
- Floating navigation that changes state while scrolling
- Responsive desktop and mobile layout
- Three product articles with reading progress and previous/next navigation
- Visual & UI Archive with lazy infinite feed, category filters, and lightbox previews
- Placeholder art until approved project assets are supplied
